# AutoWebP
AutoWebP
介绍
基于ZblogPHP插件开发文档开发的图片自动转WebP格式插件

安装教程
下载全部代码文件，在您的zblogPHP网站插件目录新建一个 “AutoWebP” 文件夹，将所有代码文件包括class文件夹一起上传到AutoWebP文件夹下，然后到网站后台插件管理页面下开启 ”图片自动转 WebP 1.0.0“ 应用即可。

使用说明
本插件由【青春记忆】开发，此插件所有代码文件全部不做加密，且免费分享给广大ZblogPHP程序使用者，为zblog插件生态出一份小小小小力。作者博客：https://www.qchun.com AutoWebP主要有以下几个功能：

开启插件后，后台编辑文章时所上传的图片文件自动转换为WebP格式。
可以自定义转换WebP格式后的图片质量(无损/有损)。
可以自定义转换后的图片尺寸大小
可以自定义图片处理引擎。
