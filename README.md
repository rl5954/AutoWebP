# 图片自动转 WebP（AutoWebP）

Z-BlogPHP 插件 · 作者：青春记忆 

## 功能简介

上传 JPG / PNG / GIF / BMP 图片时自动转换为 WebP，减小图片体积、加快页面加载。
转换优先使用 Imagick，失败自动改用 GD；自动纠正手机照片的 EXIF 方向，保留 PNG 透明通道。
转换失败或环境不支持时不影响上传，图片按原图正常入库。

## 配置项（后台 → 插件管理 → 图片自动转 WebP）

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 启用转换 | 上传图片时自动转换为 WebP | 开 |
| 压缩质量 | 0-100，建议 75-85 | 82 |
| 缩放 | 最长边上限（像素），0 = 不缩放，超限等比缩小不放大 | 0 |
| 保留原图 | 保存原图文件（与 WebP 同名不同扩展名），并显示在附件管理中 | 开 |

## 自动跳过的文件

- 非图片文件（PDF、压缩包等，按文件内容识别，不看扩展名）
- 已经是 WebP 的图片
- GIF 动图（转 WebP 只能保留第一帧，会丢帧）

## 处理流程

1. 上传时按文件内容识别图片类型；
2. 勾选「保留原图」时，先把原图复制到附件目录，并在附件管理中创建对应记录；
3. 用 Imagick（优先）或 GD 把图片转换为 WebP，写入同一目录；
4. 转换成功：附件以 WebP 计入文章；失败：回退为系统默认保存原图。

原图与 WebP 存放在同一目录（`zb_users/upload/年/月/`），同名不同扩展名。
两者是独立的附件，可分别在附件管理中删除。

## 运行要求

- Z-BlogPHP 1.7+，PHP 7.0+
- Imagick 扩展（推荐）或启用 GD 的 WebP 支持（imagewebp），二者有其一即可转换
